# No refused language by default

The prose hook refuses a built-in list of French words whenever `ccgh.json` has no `language`
key. That list suited the repository ccgh grew in and no other: in a French-speaking repository
it refuses every edit to the French translations. This task removes the built-in list, so that
nothing is refused unless `ccgh.json` lists it, and makes `ccgh init` write the empty list when
the key is absent, so that a repository sees the setting it runs with. It is a task of its own
because it changes a default every consumer runs under, independently of adoption.

**Files**

- Modify: `hooks/rules/enforce-language.ts` — the default becomes an empty list
- Modify: `hooks/rules/enforce-language.test.ts` — the refusing cases pass their list explicitly
- Modify: `hooks/run.test.ts` — the refusing example uses a rule that still refuses by default
- Modify: `src/commands/init.ts` — `ccgh.json` gains `"language": { "refuse": [] }` when absent
- Modify: `src/commands/init.test.ts` — the new behaviour, and the fixture that assumed none
- Modify: `README.md` — the `language.refuse` paragraph
- Modify: `ccgh.json` — regenerated by `bun bin/ccgh init --from ./`

**Interfaces**

- Consumes: nothing.
- Produces: `ccgh.json` written by `init` always carries a `language` key. Task 4 relies on it
  when it writes `ccgh.json` into the adoption worktree.

- [x] **Write the implementation**

In `hooks/rules/enforce-language.ts`, delete the `frenchWords` array and the comment above it,
and read the list with no fallback but emptiness:

```ts
export const decide: Decide = ({ input, context }) => {
  const refused = context.configuration().language?.refuse ?? [];

  if (refused.length === 0) return null;
  // the rest is unchanged
};
```

In `src/commands/init.ts`, replace the block that writes `ccgh.json` with one that adds what is
missing and still leaves an unchanged file untouched:

```ts
const file = join(repository, "ccgh.json");
const current = existsSync(file) ? JSON.parse(await readFile(file, "utf8")) : {};
const next = {
  ...current,
  action,
  // Written rather than implied, so that a repository reads the setting it runs with.
  language: current.language ?? { refuse: [] },
};

// Only when it has something to change: rewriting a file it did not change reformats it,
// and a repository whose formatter disagrees then fails its own lint for no reason.
if (current.action !== action || current.language === undefined) {
  await writeFile(file, `${JSON.stringify(next, null, 2)}\n`, "utf8");
}
```
